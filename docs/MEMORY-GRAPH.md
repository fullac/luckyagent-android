# Android 记忆图谱

## 数据与边界

客户端继续读取 `GET /api/v1/memory/graph`，默认 `limit=300`。服务端从记忆
Markdown 的 `[[wikilink]]` 生成有向边；未解析目标以 `resolved=false` 返回。
客户端不根据标题相似度、布局距离或召回得分创造新的关系，也不修改记忆笔记。
边粗细反映返回的 `weight`，节点大小/颜色反映服务端的连接数。

显示的是已加载快照，不一定是整个 vault。服务端返回 `truncated=true` 时，图谱
标题会显示 `partial vault`。局部图谱与筛选都只作用于这个快照；被服务端限量裁掉
的笔记不会通过增加跳数自动加载。

## 使用

- 点节点查看详情和邻居；再点同一个节点或空白处清除选择。
- 拖动节点时将它临时固定，其他节点继续响应布局；松手解除固定。拖空白处平移，
  双指缩放；缩放以手指的中心为锚点。`Fit` 按当前可见节点的实际范围适配视野。
- `Notes` 打开原生节点列表，可用 TalkBack/键盘选择，不依赖 Canvas 命中。
- `Around selected` 以当前选择作为固定局部中心，`Options` 中可选 1–3 跳、入链、
  出链。随后选择邻居不会悄悄换中心；再次点击该按钮才切换中心。`All notes`
  返回全局视图。
- `Filter graph notes` 匹配标题、类别、标签、路径或 ID；只保留匹配节点之间的
  真实边。搜索时保留无边的匹配结果；局部中心始终保留，隐藏节点不能作为遍历桥梁。
- `Isolated` 向服务端请求包含孤立笔记；`Show unresolved links` 是客户端筛选。
  局部中心是筛选例外，即使它是未解析节点也保持可见。
- `Pause layout` 冻结布局，仍可缩放、平移、选择和拖动节点；`Resume layout`
  继续松弛。自动冷却完成后，`Relax layout` 可重新启动布局。
- 系统动画时长比例为零时，进入页面默认暂停，并在后台计算首张静态布局。
- 召回 seeds/hops 的颜色与路径回放继续叠加在真实拓扑上。筛选可能隐藏部分路径，
  不会修改召回结果；切回 `All notes` 并清除筛选可查看已加载的完整路径。

节点位置和布局参数仅在当前图谱组件的生命周期内保留，不写入服务器或笔记。

## 实现

这是一份独立 Kotlin 实现，借鉴标准力导向图机制，不复用或分发 Obsidian 的私有
JavaScript、WASM、Electron 或 WebView 运行时。它不是完整 Obsidian 插件：本阶段
没有附件节点、标签虚拟节点、Obsidian 查询语言或笔记编辑器。

- `ui/graph/GraphTopology.kt`：清理无效/重复边，筛选及有向 BFS 局部视图。
- `ui/graph/ForceSimulation.kt`：中心力、按端点度数分配的弹簧、Barnes–Hut
  四叉树斥力、空间桶碰撞、速度阻尼和温度冷却。没有固定矩形边界。
- `ui/graph/GraphCamera.kt`：坐标转换、锚点缩放、按实际节点范围适配。
- `ui/components/MemoryGraphPanel.kt`：Compose Canvas、交互、原生控制和节点列表。
  每个布局实例由一个协程串行拥有，物理计算在 `Dispatchers.Default` 运行，
  主线程接收不可变坐标快照；最多每 16 ms 计算一次，冷却后停止。

筛选/刷新以节点 ID 复用坐标；隐藏节点坐标保留，已移除节点坐标被清理。
调整参数、切换视图或拖动节点会重新加热，而非后台永远执行模拟。

## 验证

自动检查：

```bash
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

图谱 JVM 测试覆盖有向邻域、跳数、筛选、非法边、未解析目标、孤立节点、缩放锚点、
适配范围、坐标复用、拖拽固定/解除、碰撞、冷却和 1500 节点 hub 图的有限坐标。
GitHub Actions 的 debug job 在构建 APK 前运行单元测试。

真机/模拟器验收（仍需实际运行，不能用纯 JVM 测试代替）：

1. 使用含 `A → B → C`、`D → A`、未解析目标和孤立笔记的 vault。
2. 检查全局图与 API 边一致；搜索/隐藏未解析目标后没有虚构补边。
3. 选择 A，分别测试局部 1/2/3 跳及入链/出链开关。
4. 拖节点、松手、暂停后拖动、双指缩放、空白平移、Fit；检查画布内手势不会同时
   滚动外层列表。在画布外应仍可正常滚动页面。
5. 回放召回路径，检查 seeds/hops 与原有详情和邻居导航仍可使用。
6. 测试窄屏/平板、大字体、TalkBack 的 Notes 列表，以及系统禁用动画的首帧。
