# Android 插件管理

入口：手机抽屉和宽屏侧栏的“这台电脑 → 插件”。任务和后台黑板不在这个导航里。操作对象是设置中当前
连接的 LuckyAgent 服务，手机不执行插件。

## 可用操作

- 列表显示名称、版本、说明、已保存的启用状态、执行信任、组件数量及损坏提示；可按
  名称/说明/来源搜索，按全部、启用、停用、异常筛选。
- 详情提供来源、版本引用、子目录、安装时间、提交及技能/命令/Agent/MCP 名称。
- 安装填写 Git 仓库地址或服务端电脑的本地目录，可选 Git 版本引用与仓库子目录。
- 启停保存下一次启动使用的配置；更新从原来源重新安装；卸载前确认移除登记。
- 安装/更新的执行信任默认关闭。含 MCP/钩子的插件未授信时保持停用；纯提示词组件
  不需要执行信任。新版本重新授信，原先停用的插件更新后仍停用。

变更成功后页面显示保存结果和重启提示，不自动重启服务。卸载保留服务端不可变缓存，
防止当前运行实例丢失文件。页面开关不代表当前进程已经热加载。

## 后端合同

需要提供插件管理接口的新后端。只有 CLI 插件管理的旧服务会显示升级提示。

| Method | Path | Request |
| --- | --- | --- |
| GET | `/api/v1/plugins` | 安装列表 |
| POST | `/api/v1/plugins` | `{source, ref?, subdir?, trust?}` |
| GET | `/api/v1/plugins/{name}` | 单个插件详情 |
| POST | `/api/v1/plugins/{name}/enable` | `{}` |
| POST | `/api/v1/plugins/{name}/disable` | `{}` |
| POST | `/api/v1/plugins/{name}/update` | `{trust:false}` |
| DELETE | `/api/v1/plugins/{name}` | 无请求体 |

列表响应 `{plugins:[...],count,changes_require_restart:true}`；成功变更响应包含
`action`、`name`、可选 `plugin`、`runtime_restart_required:true` 和 `message`。
客户端只收组件名称与安装元数据，不收提示词正文、MCP 环境变量、脚本或凭据。

请求沿用设置中的 Bearer 或 X-API-Key。插件请求固定同一份地址与鉴权快照；切换连接时
取消旧请求并清空旧列表，旧响应不会覆盖新服务状态。安装/更新请求最多等待 110 秒，
服务端 Git/复制操作限时 90 秒；失败不自动重试写操作，会刷新实际安装状态。

加载失败保留已读取列表并展示重试入口；变更操作串行处理；失败不会把开关伪装为成功。
没有新增安卓依赖或后端配置键。
