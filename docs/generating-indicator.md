# 聊天主页「生成中」

输入栏上方的「生成中」只表示当前会话里 Agent 正在回复。它不看任务列表。

- 本机发出、还没收到结束、取消或错误的回合，会显示「生成中」。
- 服务端在同一帧上明确写出 `executing`、`running` 或 `in_progress` 时，重连回放也可以点亮它。
- 历史 `status`、`reasoning`、`tool_call` 只更新记录，不登记新的运行，也不能把指示重新点亮。
- 没有请求号的 `connected` / `reconnected` 只是连接通知。切换会话时它不能匹配前台回合，也不能点亮「生成中」。
- `error`，包括 `websocket journal sequence gap`，会清掉当前会话的运行、`isResponding` 和仍标着 `streaming` 的气泡，并显示失败和下一步。带了请求号的错误按会话收尾；对不上请求号的错误只在当前会话兜底，因为那帧可能不属于任何在跑的回合。
- 历史页已经以最终助手回复结尾，且本机没有这条回合的发送租约时，清掉回放登记和「生成中」。待工具结果的一轮不算最终回复。
- 斜杠命令仍显示「执行中」。任务卡片、通知落点和导航不由这条指示负责。

服务端日志序号缺口的修复不在这个客户端改动里。
