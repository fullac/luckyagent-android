# SVG 预览

状态：本地实现，已开 PR。尚未在设备上点过。

## 做法

完整、静态的 SVG 不再走整页 HTML 预览。

- 消息卡片按 `viewBox` 或宽高比显示整张图。没有框时先用正方形，布局量到尺寸后再改。
- 图比一屏的 72% 更高时，在卡片里滚动，不再用 480dp 裁掉。
- 右上角打开全屏。全屏可以缩放，源码页显示完整文本。
- 卡片离开组合时销毁 WebView。历史里滑出屏幕的图不再常驻。
- 尺寸只读根节点的 `getBBox`，不再扫描全部节点。
- 带 `script`、`foreignObject` 或外部 `href` / `src` 的 SVG 仍走原来的 HTML 预览和资源策略。

## 不做

- 不改图片附件的 480dp 上限。
- 不改 `details` 折叠。
- 不改服务端，不改桌面 GUI。

## 验收

`SvgPreviewTest` 覆盖框、卡片高度、滚动、脚本回退、完整源码包装和单次测量。
